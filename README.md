# Мій сайт

Навчальний статичний сайт: три сторінки, HTML5, CSS, JavaScript без залежностей. Жодних зовнішніх API і CDN.

Опублікований сайт: https://andrii-kovalov7.github.io/web-tech-site/

## Перегляд локально

Одна команда з папки site:

    python3 -m http.server 8000

Далі відкрити в браузері http://localhost:8000

## Сторінки

- index.html, головна сторінка з картками, розкриваючим блоком і формою зворотного зв'язку
- pages/about.html, проєкт і його структура
- pages/quiz.html, квіз з чотирма запитаннями, результат рахує JavaScript

## Файли

- css/style.css, єдина таблиця стилів, світла і темна палітри, адаптивні правила
- js/main.js, перемикач теми з збереженням у localStorage, перевірка форми, логіка квіза
- images/, зображення WebP і логотип SVG

## Публікація на GitHub Pages

1. Створити новий repository на GitHub, назва може бути будь-якою, наприклад web-course.
2. Завантажити всі файли цієї папки в repository так, щоб index.html був у корені.
3. У repository відкрити Settings, Pages.
4. У розділі Source вибрати Deploy from a branch, гілку main і каталог (root).
5. Зберегти. Через хвилину сайт буде доступний за адресою https://ВАШ_ЛОГІН.github.io/НАЗВА_REPOSITORY.

У файлах сайта немає імен, груп чи організацій, тому публікація нейтральна.
