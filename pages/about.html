Головна Про сайт Квіз

Про сайт

Сайт створено в межах курсу вебтехнологій як підсумковий навчальний проєкт. Це статичний сайт: три сторінки, спільний файл стилів і один файл JavaScript без залежностей.

Для кого

Для тих, хто починає вивчати веброзробку. Сайт коротко показує, за що відповідають HTML, CSS і JavaScript, і дає змогу перевірити себе в квізі.

Структура

Сторінка Що містить
Головна Опис проєкту, картки HTML, CSS і JavaScript, розкривний блок і демонстраційна форма зворотного зв'язку.
Про сайт Призначення, структура, технології та публікація сайта.
Квіз Чотири запитання з перевіркою відповідей у браузері.

Технології

  • HTML5: семантичні теги header, nav, main, section, article і footer, форми з label, fieldset і legend.
  • CSS3: один файл css/style.css, сітка карток на flexbox, медіазапит для екранів до 600 пікселів, переходи transition, анімація keyframes, object-fit для зображень, світла і темна палітри.
  • JavaScript: js/main.js перемикає тему і зберігає вибір у localStorage, перевіряє форму і рахує результат квіза.
  • Зображення: власні ілюстрації у форматі WebP і логотип у форматі SVG.

Публікація

Сайт розміщено на GitHub Pages за адресою andrii-kovalov7.github.io/web-tech-site, вихідний код відкритий у репозиторії github.com/Andrii-Kovalov7/web-tech-site.

Щоб переглянути сайт локально, у папці з файлами виконайте python3 -m http.server 8000 і відкрийте адресу http://localhost:8000.
